# Factory

A first-person factory builder: start with a drill on one planet, grow a factory that assembles the ship you fly off-world, then make two planets with different rules feed each other.

## Run it

1. Install [Godot 4.3](https://godotengine.org/download/archive/4.3-stable/).
2. Clone this repo.
3. In Godot's Project Manager, click **Import** and pick `project.godot`.
4. Press **F5** to play.
